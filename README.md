# She Can Foundation MERN Contact Form

A full-stack MERN internship task project with a responsive orange, black, and white UI, form validation, Express APIs, and MongoDB-ready storage.

## Features

- React + Vite frontend
- Express + Node backend
- MongoDB integration with Mongoose
- Contact form with name, email, and message fields
- Frontend and backend validation
- Success message after submit
- Admin submissions endpoint
- Responsive design

## Setup

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start Backend Server:

   ```bash
   cd server
   npm start
   The backend runs on `http://localhost:5000`.
   ```

3. Start Frontend:

   ```bash
   cd client 
   npm run dev
   Frontend runs on `http://localhost:5173`
   ```
   
Open the frontend at `http://localhost:5173`.
